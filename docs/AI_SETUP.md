# AI: Gemini, Groq, OpenRouter

SOLIK работает с несколькими бесплатными провайдерами и переключается между ними сам. Если у одного кончился лимит или он недоступен, запрос уходит к следующему.

| Провайдер | Ключ | Что делает |
|---|---|---|
| Google Gemini | https://aistudio.google.com/apikey → `GEMINI_API_KEY` | тексты и изображения |
| Groq | https://console.groq.com/keys → `GROQ_API_KEY` | тексты (быстрые открытые модели) |
| OpenRouter | https://openrouter.ai/keys → `OPENROUTER_API_KEY` | тексты, бесплатные модели `:free` выбираются автоматически |

```
AI_PROVIDER=auto            # Gemini -> Groq -> OpenRouter; или gemini | groq | openrouter | none
GEMINI_TEXT_MODEL=gemini-2.5-flash
GEMINI_IMAGE_MODEL=gemini-2.5-flash-image
GROQ_MODEL=llama-3.3-70b-versatile
OPENROUTER_MODEL=           # пусто = любая доступная бесплатная модель
```

Модели задаются переменными, поэтому при выходе новых версий меняйте значение без правки кода. Состояние провайдеров видно в Админ-панели → «Логи и интеграции».

> Эти сервисы недоступны из некоторых регионов (в том числе из России): API отвечает `403`. Сервер с SOLIK должен находиться там, где они работают, например в Нидерландах.

## Тексты
`POST /api/ai/generate` ставит задачу в `AIContentQueue`. Gemini возвращает структурированный JSON (`responseSchema`) с полями: заголовок, текст, призыв, описание, краткий текст, полный пост. Результат санитизируется до HTML-тегов Telegram. Промпт запрещает выдумывать условия и ссылки.

## Изображения
`POST /api/ai/image` → `AIImageQueue`:
1. Gemini генерирует только **фон и сюжет**, без текста и логотипов. Стили: «Мультяшная иллюстрация» (как в примерах победных постов), «Премиум тёмный», «Минимализм».
2. Sharp накладывает SVG-слой с названием, плашкой приза и датой, затем логотип.
3. Логотип **не генерируется**: используется `BRAND_LOGO_PATH` (SOLIK) или логотип, загруженный владельцем White-Label бота.
4. Итог — JPEG 1280×720, пригодный для Telegram. Сохраняется как `MediaFile` и может быть сразу прикреплён к посту.

Если AI-фон недоступен (нет ключа, кончилась квота), картинка всё равно создаётся по фирменному шаблону: градиент, текст, логотип.

## Замена провайдера
Интерфейс `AIProvider` (`modules/ai/provider.ts`): `generatePost`, `generateImage`. Новый провайдер добавляется отдельным файлом и веткой в `getAIProvider()`.
