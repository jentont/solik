# Безопасность

| Требование | Реализация |
|---|---|
| Проверка Telegram Web App initData | HMAC-SHA256 (`WebAppData` → токен бота), timing-safe сравнение, срок `auth_date` ≤ 24 ч (`telegram/initData.ts`) |
| Login Widget | SHA256(токен) как ключ HMAC, проверка срока |
| Аутентификация | JWT HS256 (`jose`), httpOnly + SameSite=Lax cookie для веба; в Mini App токен хранится только в памяти, не в localStorage |
| CSRF | изменяющие запросы с cookie требуют заголовок `x-solik-csrf: 1`, что вынуждает CORS-preflight; CORS разрешён только для `WEB_APP_URL` |
| Авторизация и изоляция | все запросы фильтруются по владельцу (`http/ownership.ts`); чужой ID → 404, как будто ресурса нет |
| RBAC | `USER` / `ADMIN` / `OWNER`; роли и цены тарифов меняет только OWNER; роль перечитывается из БД на каждый запрос, блокировка действует сразу |
| Rate limiting | `@fastify/rate-limit` на Redis: общий лимит и строгие лимиты для входа, загрузок, AI, тестовых отправок |
| SQL Injection | Prisma (параметризованные запросы); raw SQL только через tagged templates |
| XSS / HTML injection | шаблоны санитизируются до whitelist тегов Telegram, значения переменных экранируются, ссылки только `https://` и `tg://`; превью рендерится на сервере |
| Проверка webhook | секрет на каждого бота (`secret_token`), timing-safe; идемпотентность по `update_id` |
| Хранение токенов | AES-256-GCM (`ENCRYPTION_KEY`), токен не отдаётся клиенту, сообщение с токеном в боте удаляется |
| API-ключи | только в env на сервере; Gemini-ключ передаётся заголовком; файлы и стикеры Telegram проксируются, токен в браузер не попадает |
| Загрузки | тип определяется по сигнатуре файла, изображения перекодируются (метаданные удаляются), лимит размера; медиа отдаются по подписанным ссылкам |
| Платежи | проверка суммы, валюты и плательщика в `pre_checkout_query` и повторно при `successful_payment`; уникальный charge id; автовозврат при проигранной гонке |
| Audit log | `ActivityLog`: входы, конкурсы, розыгрыши, выдачи, подписки, все изменяющие админ-запросы |
| Рассылки | только подключенные чаты и пользователи, сами начавшие диалог с ботом; заблокировавшие исключаются автоматически |
| Telegram Business | только официальные права Bot API, выданные владельцем аккаунта; MTProto-сессии не используются |
| Секреты в репозитории | `.env` в `.gitignore`, есть `.env.example` |

## Рекомендации по эксплуатации
- Сгенерируйте уникальные `JWT_SECRET` и `ENCRYPTION_KEY`, не используйте значения из примера.
- `ALLOW_DEV_LOGIN` в production игнорируется, но держите его выключенным.
- Ограничьте доступ к портам PostgreSQL и Redis: в compose они не публикуются.
