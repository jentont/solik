# Боты, чаты и каналы

## Главный бот SOLIK
Создайте бота в @BotFather и укажите токен в `MAIN_BOT_TOKEN`. Webhook, команды (`/start`, `/newbot`, `/help`) и кнопка Mini App настраиваются автоматически при старте API (или командой `npm run set-main-webhook -w apps/api`).

Меню `/start`: Создать бота · Мои боты · Конкурсы · Розыгрыши · Telegram Gifts · SMS Counter · Аналитика · Настройки · Добавить в чат · Помощь.

## Бесплатный режим: бот SOLIK в своих чатах
1. «Добавить в чат» (deep link `?startgroup=…&admin=…` сразу запрашивает нужные права).
2. Бот должен быть **администратором**: так он видит все сообщения, может проверять подписки и публиковать.
3. Чат появится в панели автоматически (`my_chat_member`). Владельцем станет тот, кто добавил бота.

## Собственный White-Label бот
1. «Создать бота» → оплата подписки в Telegram Stars (100 ⭐ / 30 дней по умолчанию, с явным согласием на автопродление).
2. @BotFather → /newbot → токен отправляется боту SOLIK (сообщение удаляется) или вводится в панели.
3. SOLIK проверяет токен (`getMe`), шифрует его, ставит webhook с секретом и команды.
4. Панель бота → «Внешний вид»: название, описание, аватар, приветствие с медиа, кнопки меню, команды. Бот нигде не упоминает SOLIK.

Если подписка истекла: 3 дня льготного периода (настраивается), затем статус `SUBSCRIPTION_EXPIRED`. Данные не удаляются, но новые конкурсы недоступны. Продление сразу возвращает бота в работу.

Отмена автопродления выполняется через `editUserStarSubscription`, бот работает до конца оплаченного периода.

## Каналы и комментарии
- Добавьте бота администратором **в канал** (право публикации) и **в группу обсуждения**.
- Пост канала автоматически пересылается в группу обсуждения (`is_automatic_forward`). SOLIK запоминает связь `пост → ветка`.
- «Первый комментарий» и SMS по комментариям считают только ответы в ветке выбранного поста.
- Бот видит только посты, опубликованные после его добавления. Поэтому удобнее, чтобы конкурсный пост публиковал сам бот.

## Статусы чатов
`ACTIVE`, `INACTIVE`, `BOT_REMOVED`, `BOT_RESTRICTED`, `PERMISSION_MISSING`, `DISCONNECTED`, `SUSPENDED`. Обновляются автоматически по `my_chat_member` и ошибкам отправки. Вручную права перепроверяются кнопкой ⟳.

## SMS Counter в чате
```
.sms 100         первые 100 уникальных участников
.sms msg 100     первые 100 сообщений
.sms every 5 20  каждый 5-й комментарий, 20 мест
.sms first       первый комментарий
.sms stats | winner | stop | reset | help
```
Команды принимаются только от администраторов чата, включая анонимных и от имени связанного канала. Отправленная в ветке комментариев команда считает только этот пост, в основном чате — сообщения группы. Призы по позициям задаются в панели бота (вкладка «SMS-призы») или при запуске из панели.

## Перебивка через платные сообщения
Включите в настройках группы «Платные сообщения» (N ⭐ за сообщение) и создайте конкурс «Перебивка» с режимом «Платные сообщения». Каждое оплаченное сообщение делает автора лидером и сбрасывает таймер. Stars получает владелец чата по правилам Telegram.

## Конкурс 777
Тип «Конкурс 777»: участники отправляют 🎰 в чат. Значение 64 (три семёрки) выигрывает. Результат генерирует Telegram, пересланные кубики не засчитываются.
