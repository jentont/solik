# Подарки, Stars, Business и NFT

## Импорт ID подарков
Формат описан в `data/README.md`. Способы импорта:
- Админ-панель → «Подарки и эмодзи» → вставить JSON → «Импортировать»;
- `npm run import:gifts` (читает `data/gifts.json`).

Изображения подарков положите в `apps/web/public/gifts/` и укажите `imageUrl: "/gifts/имя.png"`.

**Наличие ID не гарантирует, что подарок можно отправить.** После импорта и каждые 6 часов выполняется `getAvailableGifts`:
- подарок есть в списке → `transferable=true`, возможна автовыдача (`sendGift`);
- подарка нет в списке → `transferable=false`, только ручная выдача;
- `remaining_count=0` → `SOLD_OUT`.

## Как выдаётся приз

| Приз | Метод | Условие |
|---|---|---|
| Обычный или лимитированный подарок | `sendGift` | подарок подтверждён и на балансе Stars бота хватает средств (проверяется `getMyStarBalance`) |
| Коллекционный (NFT) подарок | `transferGift` через Telegram Business | подарок есть в аккаунте владельца, выданы права «Передача подарков», `can_be_transferred` |
| Telegram Premium | `giftPremiumSubscription` | 3, 6 или 12 месяцев (1000, 1500 или 2500 ⭐ с баланса бота) |
| Stars | ручная выдача | Bot API не позволяет боту переводить Stars пользователям |
| Удалённый подарок / собственный приз | ручная выдача | |
| NFT (TON и др.) | провайдер из `modules/nft/providers.ts` | только при подтверждённой интеграции, иначе ручная выдача |

Статусы выдачи: `PENDING → PROCESSING → DELIVERED`, `FAILED` (можно повторить), `MANUAL_REQUIRED`. При ручной выдаче владелец получает от бота SOLIK сообщение с инструкцией и отмечает выдачу в панели. Фиктивной «автовыдачи» нет. Если процесс прервался в `PROCESSING`, повторной отправки не будет: выдача переводится в `MANUAL_REQUIRED` для проверки, чтобы подарок не ушёл дважды.

## Баланс Stars бота
Бот покупает подарки со своего баланса. Пополнить его можно переводом Stars боту. Баланс виден в карточке бота.

## Telegram Business
1. Нужен Telegram Premium у владельца.
2. Настройки → Telegram для бизнеса → Чат-боты → выберите своего бота (или бота SOLIK) и включите права «Просмотр подарков и звёзд» и «Передача подарков».
3. Подключение придёт как `business_connection`. Подарки аккаунта синхронизируются (`getBusinessAccountGifts`) и становятся доступны как призы с автопередачей.

## Premium Emoji
Импорт: `data/premium-emoji.json` → `npm run import:emoji`, или через админ-панель. Превью загружаются через `getCustomEmojiStickers`. В сообщениях эмодзи передаются entity `custom_emoji` (`<tg-emoji emoji-id>`), а не обычными символами. Если Telegram отклонит их для бота в конкретном контексте, сообщение будет отправлено повторно с символом-заменителем.

## NFT-провайдеры
Чтобы подключить реальную передачу (например, TON), реализуйте `transfer()` в `modules/nft/providers.ts` с подписанием транзакций вашим кошельком-хранителем, выставьте `canTransfer: true` и задокументируйте переменные окружения. До этого NFT-призы выдаются вручную.
