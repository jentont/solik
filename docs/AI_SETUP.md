# AI (Gemini)

1. Получите ключ в Google AI Studio.
2. `.env`:
   ```
   AI_PROVIDER=gemini
   GEMINI_API_KEY=...
   GEMINI_TEXT_MODEL=gemini-2.5-flash
   GEMINI_IMAGE_MODEL=gemini-2.5-flash-image
   ```
   Модели задаются переменными: при выходе новых версий меняйте значение без правки кода.
3. Перезапустите `api` и `worker`. Статус виден в Админ-панели → «Логи и интеграции».

## Тексты
`POST /api/ai/generate` ставит задачу в `AIContentQueue`. Gemini возвращает структурированный JSON (`responseSchema`) с полями: заголовок, текст, призыв, описание, краткий текст, полный пост. Результат санитизируется до HTML-тегов Telegram. Промпт запрещает выдумывать условия и ссылки.

## Изображения
`POST /api/ai/image` → `AIImageQueue`:
1. Gemini генерирует только **фон и сюжет**, без текста и логотипов. Стили: «Мультяшная иллюстрация» (как в примерах победных постов), «Премиум тёмный», «Минимализм».
2. Sharp накладывает SVG-слой с названием, плашкой приза и датой, затем логотип.
3. Логотип **не генерируется**: используется `BRAND_LOGO_PATH` (SOLIK) или логотип, загруженный владельцем White-Label бота.
4. Итог — JPEG 1280×720, пригодный для Telegram. Сохраняется как `MediaFile` и может быть сразу прикреплён к посту.

Без ключа Gemini доступна генерация по фирменному шаблону (градиент + текст + логотип).

## Замена провайдера
Интерфейс `AIProvider` (`modules/ai/provider.ts`): `generatePost`, `generateImage`. Новый провайдер добавляется отдельным файлом и веткой в `getAIProvider()`.
